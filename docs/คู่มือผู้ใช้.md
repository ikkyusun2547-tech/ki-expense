# คู่มือผู้ใช้ ระบบเบิกค่าบริการ (ค่าอินเทอร์เน็ต · ค่าโทรศัพท์)

บริษัท น้ำตาลสุรินทร์ จำกัด · ฝ่ายจัดหาวัตถุดิบ

## เข้าใช้งาน

1. เปิดเบราว์เซอร์ (Chrome หรือ Edge) ไปที่ที่อยู่ระบบที่ผู้ดูแลระบบแจ้ง เช่น `http://IT5:8080`
2. กรอก **ชื่อผู้ใช้** และ **รหัสผ่าน** ที่ได้รับจากผู้ดูแลระบบ
3. เข้าครั้งแรก ระบบจะให้**ตั้งรหัสผ่านใหม่ของตัวเอง** (อย่างน้อย 8 ตัวอักษร)

- **จดจำฉันไว้ 30 วัน** (ติ๊กไว้ให้แล้ว) — ไม่ต้องพิมพ์รหัสทุกวัน · ถ้าใช้เครื่องร่วมกับคนอื่น ให้เอาติ๊กออก

- ลืมรหัสผ่าน → แจ้งผู้ดูแลระบบให้ตั้งรหัสใหม่
- ใส่รหัสผิด 5 ครั้ง ระบบจะล็อกชั่วคราว 15 นาที
- **เมนูอยู่ด้านบน** (มือถือ: แถบเมนูด้านล่างจอ แบบแอป) — ผู้จัดทำมี **หน้าแรก / ศูนย์ & เบอร์ / ใบเบิก**
- เปลี่ยนรหัสผ่าน / ออกจากระบบ: กดชื่อของคุณที่มุมขวาบน
- **ตัวเลขบนเมนู** = งานที่รอคุณทำ เช่น "รออนุมัติ 3" หรือใบเบิกของคุณที่ยังไม่ส่ง
- ค่าอินเทอร์เน็ต / ค่าโทรศัพท์ เลือกด้วย**แท็บในหน้า** (หน้าศูนย์ & เบอร์ และหน้าใบเบิก)

## ขั้นตอนการเบิก (ภาพรวม)

ใบเบิกยังเป็น**กระดาษเซ็นมือ** — ระบบใช้ติดตามว่าเอกสารอยู่ที่ใคร ถึงฝ่ายบัญชีแล้วหรือยัง (ทุกคนกดในระบบเมื่อเอกสารผ่านมือตัวเอง)

```
ผู้จัดทำ: พิมพ์ใบเบิก + กด "ส่งขออนุมัติ" → ผู้อนุมัติ: เซ็น + กด "อนุมัติ" → ส่งกระดาษไปบัญชี → บัญชี: กด "รับเอกสาร" → จ่ายเงิน + กด "บันทึกจ่าย"
        (สร้างแล้ว)                         (รออนุมัติ)                  (อนุมัติแล้ว)              (บัญชีรับแล้ว)              (จ่ายแล้ว)
```

- หน้าใบเบิกบอก **"เอกสารอยู่ที่ …"** (ผู้จัดทำ / ผู้อนุมัติ / กำลังส่งไปฝ่ายบัญชี / ฝ่ายบัญชี) — ไม่ต้องโทรถาม

- ผู้อนุมัติกด **ไม่อนุมัติ** (พร้อมเหตุผล) → ใบเบิกกลับเป็น "สร้างแล้ว" ให้ผู้จัดทำแก้แล้วส่งใหม่
- ยังพิมพ์ใบเบิกไปเซ็นบนกระดาษได้เหมือนเดิม เมื่ออนุมัติในระบบแล้ว ใบเบิกจะพิมพ์ "อนุมัติในระบบ วันที่ เวลา" ใต้ชื่อผู้อนุมัติ

## สำหรับผู้จัดทำ

### สร้างใบเบิก (ทางลัด)

เข้าระบบแล้วจะเจอ **หน้าแรก**: ปุ่มใหญ่ **เบิกค่าอินเทอร์เน็ต** / **เบิกค่าโทรศัพท์** (บอกจำนวนศูนย์ และใบที่**กำลังดำเนินการ** = สร้างแล้วแต่ยังไม่ถึงขั้นจ่ายเงิน)
และ **ใบเบิกของฉันอยู่ที่ไหน** — แถบความคืบหน้าของทุกใบที่ยังไม่จ่าย (ผู้จัดทำ → ผู้อนุมัติ → ส่งบัญชี → บัญชีรับ → จ่ายแล้ว)

1. ใบแจ้งหนี้มา → กดปุ่มใหญ่ของประเภทนั้น → จะเจอ**การ์ดของแต่ละศูนย์** → พิมพ์ในช่อง **ค้นหา** (ชื่อศูนย์ / รหัสลูกค้า / หมายเลขบริการ — การ์ดกรองทันที) → **กดการ์ดศูนย์นั้น**
   (เหลือการ์ดเดียวกด Enter ได้เลย · เมนู **ใบเบิก** → **+ สร้างใบเบิก** ก็มาที่หน้านี้)
2. ฟอร์มขึ้นศูนย์ที่เลือกไว้แล้ว (ผิดศูนย์กด **เปลี่ยนศูนย์**) ระบบ**กรอกให้ล่วงหน้า**: ยอดปกติ, รอบบริการถัดจากใบล่าสุด, วันครบกำหนด, ผู้อนุมัติคนเดิม
   ตรวจให้ตรงใบแจ้งหนี้ (แก้ได้) แล้วกรอกแค่
   - **เลขที่ใบแจ้งหนี้** (เคอร์เซอร์รออยู่ที่ช่องนี้แล้ว)
   - **แนบไฟล์ใบแจ้งหนี้** (PDF, JPG หรือ PNG ไม่เกิน 10MB)
   - อยากเห็นหน้าตาใบเบิกก่อนบันทึก → กด **ดูตัวอย่าง PDF** (เปิดแท็บใหม่ มีลายน้ำ "ตัวอย่าง" — ยังไม่บันทึกอะไร ใช้พิมพ์จริงไม่ได้)
3. กด **สร้างและส่งขออนุมัติ** → เสร็จ ระบบพากลับหน้าสรุปรายศูนย์ให้ทำศูนย์ถัดไป
   ยังไม่พร้อมส่ง → กด **บันทึกไว้ก่อน** (ส่งทีหลังได้จากหน้าใบเบิก)

**ถ้าระบบไม่ให้บันทึก** (กล่องสีแดง) ต้องแก้ก่อน เช่น
- ศูนย์นี้มีใบเบิกรอบบริการที่ทับกันอยู่แล้ว (กันเบิกซ้ำ)
- ศูนย์อยู่ในสถานะ "ย้าย" หรือ "ปิด"
- กรอกข้อมูลไม่ครบ หรือวันสิ้นสุดอยู่ก่อนวันเริ่ม

**ถ้าระบบเตือน** (กล่องสีเหลือง) ตรวจแล้วกด **ตรวจแล้ว ยืนยันบันทึก** ได้ เช่น
- รอบบริการสั้นกว่า 25 วัน หรือยาวกว่า 35 วัน
- ยังไม่ได้แนบไฟล์ใบแจ้งหนี้

ยอดไม่เท่ากับยอดปกติ → มีข้อความสีเหลืองใต้ช่องยอดให้ตรวจ แต่**บันทึกได้เลย ไม่ต้องกดยืนยันซ้ำ**

### ใบเบิกค่าโทรศัพท์

ทำเหมือนค่าอินเทอร์เน็ตทุกขั้นตอน ต่างแค่ช่องค้นหา:
หน้าแรก → **เบิกค่าโทรศัพท์** (หรือเมนู **ศูนย์ & เบอร์** → แท็บ **ค่าโทรศัพท์**) → ค้นหา**เบอร์โทรศัพท์**ตามใบแจ้งหนี้ (เช่น 097-3378822 จะมีขีดหรือไม่ก็ได้) หรือชื่อฝ่าย → กดการ์ดเบอร์นั้น
ระบบรู้เองว่าเป็นค่าโทรศัพท์ แล้วกรอกวันครบกำหนด และข้อความบนใบเบิก (จาก / เรียน / เพื่อ) ตามใบค่าโทรศัพท์ใบล่าสุดให้
ยอดเงินกรอกตามบิล 2 ช่อง (ก่อนภาษีมูลค่าเพิ่ม): **ค่าบริการแพ็กเกจหลัก** (ระบบใส่ให้) และ **ค่าแพ็กเกจเสริมและค่าบริการส่วนเกิน** (ไม่มี = 0)
ระบบคิด VAT 7% และยอดรวมให้เอง — เทียบกับบรรทัด "รวมค่าบริการรอบบิลปัจจุบัน" ในบิลได้ทันที (ผู้อนุมัติ/บัญชีเห็นยอดแยกเป็นตารางในหน้าใบเบิก — ใบเบิก PDF ไม่พิมพ์ยอดแยก)
ใบเบิก PDF จะเป็น "ขอเบิกค่าใช้บริการโทรศัพท์" ตามฟอร์มเดิม (ตารางมีหมายเลขโทรศัพท์ + ระบบ)

### หลังสร้างใบเบิก

เปิดใบเบิกจากเมนู **ใบเบิก** → กด **ดู**

**ดูว่าเดือนไหนทำเรื่องเบิกอะไรไปบ้าง**: เมนู **ประวัติ** (ทุกบทบาท) — การ์ดเดือนละใบ: สร้างกี่ใบ ยอดรวม แยกค่าอินเทอร์เน็ต / ค่าโทรศัพท์ และแถบสีว่าแต่ละใบถึงขั้นไหน
(การ์ดเขียว = จ่ายครบทุกใบ · ฟ้า = ยังมีใบค้าง) → กด **ดูรายการ** เห็นทุกใบของเดือนนั้น พร้อมวันที่สร้างและผู้สร้าง
นับตาม**วันที่สร้างใบเบิกในระบบ** (ไม่ใช่วันครบกำหนดชำระ) · เลือกแท็บประเภทเพื่อดูเฉพาะค่าอินเทอร์เน็ตหรือค่าโทรศัพท์

- **แก้ไข** / **ลบ** — ทำได้เฉพาะใบที่สถานะ "สร้างแล้ว" และ**เป็นใบที่คุณสร้างเอง** (ใบของคนอื่นเปิดดู/พิมพ์ได้อย่างเดียว — ถ้าเจ้าของใบไม่อยู่ ให้ผู้ดูแลระบบโอนใบให้)
- **ผู้ลงนามในใบเบิก** (กล่องด้านขวา) — เลือก **ผู้อนุมัติ** (บังคับ) และ **ผู้ขออนุมัติ** (ถ้าไม่เลือก = ตัวผู้จัดทำเอง)
  ตำแหน่งเปลี่ยนตามคนที่เลือกอัตโนมัติ แล้วกด **บันทึกผู้ลงนาม**
  ไม่มีชื่อที่ต้องการในรายการ → แจ้งผู้ดูแลระบบให้สร้างบัญชีผู้ใช้ให้คนนั้น
- กด **พิมพ์ใบเบิก (PDF)** → ไฟล์เปิดในแท็บใหม่ → สั่งพิมพ์ (Ctrl+P) ถ้าต้องการเอกสารกระดาษ
  ใบเบิกเป็นแบบ "บันทึกภายใน" (FM-50000-02) วันที่เป็น พ.ศ. ยอดเงินเป็นตัวหนังสือ และผู้ลงนามตามที่เลือกไว้
- กด **ส่งขออนุมัติ** → ใบเบิกไปอยู่ในเมนู **รออนุมัติ** ของผู้อนุมัติคนนั้น
  หลังจากนี้แก้ไขไม่ได้ ถ้าต้องแก้ ให้ผู้อนุมัติกด "ไม่อนุมัติ" หรือติดต่อผู้ดูแลระบบให้ "ย้อนสถานะ"

### ข้อความบนใบเบิก (จาก / เรียน / เพื่อ)

อยู่ในฟอร์มใบเบิกแต่ละใบ ส่วน **ข้อความบนใบเบิก** (พับไว้ใต้ผู้ลงนาม) — ระบบใส่ให้ตามใบล่าสุดของคุณ
ต้องการเปลี่ยน → กด **แก้ไข ▾** แล้วพิมพ์ใหม่ มีผลเฉพาะใบนั้น (ใบถัดไปจะใช้ข้อความล่าสุดนี้ให้อัตโนมัติ)

### การ์ดศูนย์ / เบอร์

เมนู **ศูนย์ & เบอร์** แสดงการ์ดทุกศูนย์ที่ใช้งานอยู่ (แท็บ **ค่าโทรศัพท์** = ทุกเบอร์)
ระบบ**ไม่เตือนวันครบกำหนด** — ใบแจ้งหนี้แต่ละที่มาไม่ตรงกัน ใบแจ้งหนี้มาเมื่อไรค่อยสร้างใบเบิก
การ์ดบอก**ใบเบิกล่าสุด**ของศูนย์นั้น (รอบบริการ + สถานะ) **สีการ์ด = สถานะของใบล่าสุด**:
⚪ ยังอยู่ที่ผู้จัดทำ / ยังไม่เคยเบิก · 🟡 รออนุมัติ · 🔵 อนุมัติแล้ว (ส่งบัญชี) · 🟣 บัญชีรับแล้ว · 🟢 จ่ายแล้ว
กดการ์ด = **สร้างใบเบิก** (ลิงก์ **ดูใบล่าสุด** เปิดใบเดิม) · ถ้าใบล่าสุด**ยังไม่ส่ง** (สร้างแล้ว) กดการ์ด = **ทำต่อ** เปิดใบนั้นเพื่อแก้/ส่งขออนุมัติ (ลิงก์ **สร้างใบใหม่** ใช้เมื่อจำเป็นจริง — รอบที่ซ้ำกับใบเดิม ระบบกันให้)

**ตารางรายปี (Excel)** — แทนตารางสรุปที่เคยเขียนมือ: ท้ายหน้า **ศูนย์ & เบอร์** (แท็บค่าอินเทอร์เน็ต หรือค่าโทรศัพท์) → เลือกปี → **ดาวน์โหลด** (ทุกคนดาวน์โหลดได้)
- 1 แถว = 1 ศูนย์ แต่ละเดือนมี **ค่าบริการ / กำหนดชำระ / รอบค่าบริการ** และมีแถว **รวม** ต่อเดือน + คอลัมน์ **รวมทั้งปี**
- ใบเบิกอยู่เดือนของ **วันครบกำหนดชำระ** · **พื้นเหลือง = ยังไม่จ่าย** · ศูนย์ที่ย้ายแล้วเป็นตัวสีเทา และเดือนหลังจากนั้นเขียน "ย้ายศูนย์"
- เริ่มจากเดือนแรกที่มีใบเบิกในปีนั้น · พิมพ์ได้ (A4 แนวนอน หัวตารางและชื่อศูนย์พิมพ์ซ้ำทุกหน้า)

## สำหรับผู้อนุมัติ

1. เมนู **รออนุมัติ** แสดงใบเบิกที่ผู้จัดทำเลือกคุณเป็นผู้อนุมัติ เรียงตามวันครบกำหนดใกล้สุด
2. ตรวจยอดในแถว (กด **เปิดไฟล์** เพื่อดูใบแจ้งหนี้)
3. ถูกต้อง → เซ็นใบเบิกกระดาษ แล้วกด **อนุมัติ** ในแถว → ส่งกระดาษให้ฝ่ายบัญชี
   ไม่ถูกต้อง → กด **ไม่อนุมัติ** ในแถว → พิมพ์เหตุผล → **ยืนยันไม่อนุมัติ** → ใบเบิกกลับไปให้ผู้จัดทำแก้

แท็บ **อนุมัติแล้ว** แสดงใบที่คุณอนุมัติไปแล้ว และสถานะว่าบัญชีรับเอกสาร/จ่ายหรือยัง

## สำหรับฝ่ายบัญชี

เมนู **ฝ่ายบัญชี** มี 3 แท็บ เรียงตามวันครบกำหนดใกล้สุด (🔴 เลยกำหนด · 🟡 ภายใน 7 วัน · กด **เปิดไฟล์** เพื่อดูใบแจ้งหนี้)

1. **รอรับเอกสาร** = ผู้อนุมัติอนุมัติแล้ว แต่ใบเบิกกระดาษยังไม่ถึงมือบัญชี (บอกว่าใครอนุมัติ เมื่อไร — ไว้ตามเอกสาร)
   ได้รับกระดาษแล้ว → กด **รับเอกสาร** ในแถวของใบนั้น (ทีละใบ) → ใบย้ายไปแท็บ **รอจ่าย**
2. **รอจ่าย** = รับเอกสารแล้ว — จ่ายเงินแล้วบันทึก**ทีละใบ** (ตรวจยอด/ใบแจ้งหนี้ของแต่ละใบก่อนกด; ใบที่ยังไม่กดรับเอกสาร บันทึกจ่ายไม่ได้)
   - ในแถวของใบนั้น: **วันที่จ่าย** ใส่วันนี้ไว้ให้แล้ว (แก้ได้ ห้ามเป็นวันในอนาคต) → กด **บันทึกจ่าย**
   - ต้องการใส่ **เลขอ้างอิงการจ่าย** (ไม่บังคับ เช่น เลขที่เอกสารจ่าย/เลขโอน) → กดเข้าไปในใบเบิก แล้วบันทึกจ่ายที่ฟอร์มในหน้านั้น
   ยืนยัน → ใบเบิกเป็น "จ่ายแล้ว" และ**ถูกล็อก แก้ไขไม่ได้อีก** — ตรวจข้อมูลให้ถูกก่อนกด
3. **จ่ายแล้ว** แสดงประวัติการจ่ายพร้อมเลขอ้างอิง
   - **สรุปการจ่ายรายเดือนเป็นไฟล์ Excel**: เลือกเดือน → **ดาวน์โหลด**
     ได้ไฟล์ .xlsx แยกส่วนค่าอินเทอร์เน็ต / ค่าโทรศัพท์ พร้อมยอดรวมแต่ละส่วนและรวมทั้งสิ้น — สั่งพิมพ์ได้เลย (ย่อพอดีกระดาษ A4 แนวนอน หัวตารางพิมพ์ซ้ำทุกหน้า)
     ถ้า Excel เปิดแบบ "มุมมองที่ได้รับการป้องกัน" (Protected View) กด **เปิดใช้งานการแก้ไข** เมื่อต้องการแก้ไฟล์

ได้รับเอกสารไม่ครบ/ผิด → แจ้งผู้ดูแลระบบให้ **ย้อนสถานะ** กลับไปให้ผู้จัดทำแก้

## สำหรับผู้ดูแลระบบ (admin)

เมนู **จัดการระบบ** มีแท็บ **ทะเบียนศูนย์ / ทะเบียนเบอร์โทร / ผู้ใช้** · หน้าแรกของ admin = ใบเบิกที่ยังไม่จ่ายทั้งหมดพร้อมว่าอยู่ที่ใคร

| ต้องการ | ไปที่ |
|---|---|
| เพิ่มพนักงาน | **ผู้ใช้** → **+ เพิ่มผู้ใช้** → เลือก "สร้างบัญชีให้" (ผู้จัดทำ / ผู้อนุมัติ / ฝ่ายบัญชี / ผู้ดูแลระบบ) → กรอกชื่อ ตำแหน่ง ชื่อผู้ใช้ และตั้งรหัสผ่านเริ่มต้น → แจ้งพนักงาน (ผู้จัดทำและผู้อนุมัติต้องมีตำแหน่ง เพราะพิมพ์ในใบเบิก) |
| พนักงานลืมรหัสผ่าน | **ผู้ใช้** → แก้ไข → **ตั้งรหัสผ่านใหม่** → แจ้งพนักงาน (พนักงานต้องเปลี่ยนเองตอนล็อกอิน) |
| เปลี่ยนตำแหน่งของพนักงาน | **ผู้ใช้** → แก้ไข → ตำแหน่ง (ใบเบิกที่เลือกคนนั้นไว้แล้วยังพิมพ์ตำแหน่งเดิม) |
| พนักงานลาออก | **ผู้ใช้** → แก้ไข → **โอนใบเบิกที่ยังไม่จ่าย** ให้ผู้จัดทำคนอื่น (ถ้ามี) → สถานะบัญชี **ปิดใช้งาน** |
| ผู้จัดทำลา แต่มีใบเบิกค้าง | เปิดใบเบิก → **โอนใบเบิก** → เลือกผู้จัดทำที่จะทำต่อ (แก้ไข/ลบ/ส่งได้เฉพาะเจ้าของใบ) |
| เพิ่ม/แก้ศูนย์ | **ทะเบียนศูนย์** → **+ เพิ่มศูนย์** หรือ **แก้ไข** (ช่อง **ระบบ (ค่าย)** เช่น 3BB, TRUE, AIS — พิมพ์ในใบเบิก) |
| เพิ่ม/อัปเดตหลายศูนย์ | **ทะเบียนศูนย์** → **นำเข้าจากไฟล์** → เลือกไฟล์ CSV (Excel: บันทึกเป็น CSV UTF-8) → **ตรวจไฟล์** → **นำเข้า** (มีไฟล์ตัวอย่าง CSV) |
| ศูนย์ย้าย/ปิด | **ทะเบียนศูนย์** → แก้ไข → เปลี่ยนสถานะ (ศูนย์ที่เคยมีใบเบิกลบไม่ได้) |
| เพิ่ม/แก้เบอร์โทรศัพท์ | **ทะเบียนเบอร์โทร** → **+ เพิ่มเบอร์** หรือ **แก้ไข** (หมายเลข, ระบบ เช่น TRUE, ผู้ใช้บริการ = ฝ่าย, ยอดปกติรวม VAT, วันครบกำหนด) |
| เพิ่มหลายเบอร์จาก Excel | **ทะเบียนเบอร์โทร** → **นำเข้าจากไฟล์** — เหมือนทะเบียนศูนย์ (ไฟล์ CSV · เบอร์ที่ Excel ตัดเลข 0 ข้างหน้าทิ้ง ระบบเติมให้เอง) |
| ยกเลิกเบอร์ | **ทะเบียนเบอร์โทร** → แก้ไข → สถานะ "ยกเลิก" (เบอร์ที่เคยมีใบเบิกลบไม่ได้) |
| ดูใบที่ค้างอนุมัติของทุกคน | **รออนุมัติ** (admin ดูได้ทุกใบ แต่อนุมัติแทนไม่ได้) |
| แก้ใบเบิกที่ส่งขออนุมัติ/อนุมัติ/บัญชีรับไปแล้ว | เปิดใบเบิก → **ย้อนสถานะ** → ใส่เหตุผล → ผู้จัดทำแก้ไขแล้วส่งใหม่ |

- admin ดูได้ทุกหน้า แต่**สร้างใบเบิก อนุมัติ และบันทึกการจ่ายไม่ได้** (เป็นหน้าที่ผู้จัดทำ ผู้อนุมัติ และฝ่ายบัญชี)
- ใบเบิกที่ "จ่ายแล้ว" ย้อนสถานะไม่ได้
- ทุกการเปลี่ยนแปลงของใบเบิกถูกบันทึกไว้ในส่วน **ประวัติ** ของใบเบิก (ใคร ทำอะไร เมื่อไร) และลบไม่ได้
