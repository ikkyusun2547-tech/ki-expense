# คู่มือผู้ใช้ ระบบเบิกค่าอินเทอร์เน็ต

บริษัท น้ำตาลสุรินทร์ จำกัด · ฝ่ายจัดหาวัตถุดิบ

## เข้าใช้งาน

1. เปิดเบราว์เซอร์ (Chrome หรือ Edge) ไปที่ที่อยู่ระบบที่ผู้ดูแลระบบแจ้ง เช่น `http://IT5:8080`
2. กรอก **ชื่อผู้ใช้** และ **รหัสผ่าน** ที่ได้รับจากผู้ดูแลระบบ
3. เข้าครั้งแรก ระบบจะให้**ตั้งรหัสผ่านใหม่ของตัวเอง** (อย่างน้อย 8 ตัวอักษร)

- ลืมรหัสผ่าน → แจ้งผู้ดูแลระบบให้รีเซ็ต
- ใส่รหัสผิด 5 ครั้ง ระบบจะล็อกชั่วคราว 15 นาที
- เปลี่ยนรหัสผ่านเองได้ที่เมนู **เปลี่ยนรหัสผ่าน** มุมขวาบน

## ขั้นตอนการเบิก (ภาพรวม)

```
ผู้จัดทำสร้างใบเบิก → พิมพ์ไปเซ็นอนุมัติ → กด "ส่งบัญชีแล้ว" → ฝ่ายบัญชีจ่ายเงินและบันทึกการจ่าย
   (สร้างแล้ว)                              (ส่งบัญชีแล้ว)                    (จ่ายแล้ว)
```

## สำหรับผู้จัดทำ

### สร้างใบเบิก

1. เมนู **ใบเบิก** → **+ สร้างใบเบิก**
2. พิมพ์ **รหัสลูกค้า 3BB** ตามใบแจ้งหนี้ แล้วกด **ค้นหา** (หรือกด Enter)
   ระบบจะแสดงชื่อศูนย์ ยอดปกติ และวันครบกำหนดประจำเดือน
3. กรอกข้อมูลตามใบแจ้งหนี้:
   - เลขที่ใบแจ้งหนี้
   - ยอด (บาท)
   - รอบบริการ เริ่ม – สิ้นสุด (ใต้ช่องจะแสดงวันที่เป็น พ.ศ. และจำนวนวันให้ตรวจ)
   - วันครบกำหนดชำระ
   - แนบไฟล์ใบแจ้งหนี้ (PDF, JPG หรือ PNG ไม่เกิน 10MB)
4. กด **สร้างใบเบิก**

**ถ้าระบบไม่ให้บันทึก** (กล่องสีแดง) ต้องแก้ก่อน เช่น
- ศูนย์นี้มีใบเบิกรอบบริการที่ทับกันอยู่แล้ว (กันเบิกซ้ำ)
- ศูนย์อยู่ในสถานะ "ย้าย" หรือ "ปิด"
- กรอกข้อมูลไม่ครบ หรือวันสิ้นสุดอยู่ก่อนวันเริ่ม

**ถ้าระบบเตือน** (กล่องสีเหลือง) ตรวจแล้วกด **ตรวจแล้ว ยืนยันบันทึก** ได้ เช่น
- ยอดไม่เท่ากับยอดปกติของศูนย์
- รอบบริการสั้นกว่า 25 วัน หรือยาวกว่า 35 วัน
- ยังไม่ได้แนบไฟล์ใบแจ้งหนี้

### หลังสร้างใบเบิก

เปิดใบเบิกจากเมนู **ใบเบิก** → กด **ดู**

- **แก้ไข** / **ลบ** — ทำได้เฉพาะใบที่สถานะ "สร้างแล้ว"
- กด **พิมพ์ใบเบิก (PDF)** → ไฟล์เปิดในแท็บใหม่ → สั่งพิมพ์ (Ctrl+P) แล้วนำไปให้ผู้อนุมัติเซ็น
  ใบเบิกเป็นแบบ "บันทึกภายใน" (FM-50000-02) วันที่เป็น พ.ศ. ยอดเงินเป็นตัวหนังสือ และชื่อผู้จัดทำในช่องผู้ขออนุมัติให้อัตโนมัติ
- เซ็นแล้วส่งให้ฝ่ายบัญชี → กด **ส่งบัญชีแล้ว**
  หลังจากนี้แก้ไขไม่ได้ ถ้าต้องแก้ ติดต่อผู้ดูแลระบบให้ "ย้อนสถานะ"

### ติดตามศูนย์ที่ยังไม่เบิก

เมนู **สรุปรายศูนย์** แสดงทุกศูนย์ที่ใช้งานอยู่:

| สถานะ | ความหมาย |
|---|---|
| 🔴 เลยกำหนด ยังไม่เบิก | วันครบกำหนดเดือนนี้ผ่านไปแล้ว แต่ยังไม่มีใบเบิก |
| 🟡 ใกล้ครบกำหนด ยังไม่เบิก | เหลือไม่เกิน 7 วันถึงวันครบกำหนด และยังไม่มีใบเบิก |
| ⚪ ยังไม่ถึงรอบ | ยังเหลือมากกว่า 7 วัน |
| 🟢 เบิกแล้ว | มีใบเบิกที่วันครบกำหนดอยู่ในเดือนนี้แล้ว |

กด **+ สร้างใบเบิก** ในแถวของศูนย์ ระบบจะใส่รหัสลูกค้าให้อัตโนมัติ

## สำหรับฝ่ายบัญชี

1. เมนู **ฝ่ายบัญชี** → แท็บ **รอจ่าย** แสดงใบเบิกที่ผู้จัดทำส่งมา เรียงตามวันครบกำหนดใกล้สุด
   - 🔴 เลยกำหนด · 🟡 ภายใน 7 วัน
   - กด **เปิดไฟล์** เพื่อดูใบแจ้งหนี้
2. จ่ายเงินแล้ว → กด **บันทึกการจ่าย** กรอก
   - **วันที่จ่ายจริง** (ห้ามเป็นวันในอนาคต)
   - **เลขอ้างอิงการจ่าย** (เช่น เลขที่เอกสารจ่าย/เลขโอน)
3. ยืนยัน → ใบเบิกเป็น "จ่ายแล้ว" และ**ถูกล็อก แก้ไขไม่ได้อีก** — ตรวจข้อมูลให้ถูกก่อนกด

แท็บ **จ่ายแล้ว** แสดงประวัติการจ่ายพร้อมเลขอ้างอิง

## สำหรับผู้ดูแลระบบ (admin)

| ต้องการ | ไปที่ |
|---|---|
| เพิ่มพนักงาน | **ผู้ใช้** → **+ เพิ่มผู้ใช้** → เลือกบทบาท → จดรหัสชั่วคราวที่แสดง (แสดงครั้งเดียว) ส่งให้พนักงาน |
| รีเซ็ตรหัสผ่าน | **ผู้ใช้** → แก้ไข → **รีเซ็ตรหัสผ่าน** |
| พนักงานลาออก | **ผู้ใช้** → แก้ไข → สถานะบัญชี **ปิดใช้งาน** |
| เพิ่ม/แก้ศูนย์ | **ทะเบียนศูนย์** → **+ เพิ่มศูนย์** หรือ **แก้ไข** |
| ศูนย์ย้าย/ปิด | **ทะเบียนศูนย์** → แก้ไข → เปลี่ยนสถานะ (ศูนย์ที่เคยมีใบเบิกลบไม่ได้) |
| เปลี่ยนชื่อฝ่าย / ผู้อนุมัติ / ตำแหน่งบนใบเบิก | **ตั้งค่า** → แก้แล้วกดบันทึก (ใบที่พิมพ์ต่อจากนี้ใช้ข้อความใหม่) |
| แก้ใบเบิกที่ส่งบัญชีไปแล้ว | เปิดใบเบิก → **ย้อนสถานะ…** → ใส่เหตุผล → ผู้จัดทำแก้ไขแล้วส่งใหม่ |

- admin ดูได้ทุกหน้า แต่**สร้างใบเบิกและบันทึกการจ่ายไม่ได้** (เป็นหน้าที่ผู้จัดทำและฝ่ายบัญชี)
- ใบเบิกที่ "จ่ายแล้ว" ย้อนสถานะไม่ได้
- ทุกการเปลี่ยนแปลงของใบเบิกถูกบันทึกไว้ในส่วน **ประวัติ** ของใบเบิก (ใคร ทำอะไร เมื่อไร) และลบไม่ได้
